# Binance Website Clone

A front-end clone of the Binance homepage, built from scratch with plain **HTML** and **CSS** (no frameworks, no JavaScript). This is a static UI recreation for practice purposes only — not affiliated with or endorsed by Binance.

## 🔗 Files

```
├── index.html   # Page markup / structure
├── style.css    # All styling
└── README.md    # This file
```

## 🌐 Live Demo

[cool-pegasus-289aaf.netlify.app](https://cool-pegasus-289aaf.netlify.app/)

## 📄 Sections Included

- **Navbar** — logo, nav links with dropdown arrows, search/login/signup, download, language, and theme icons
- **Hero** — user count stat, trust badges, email/phone signup form, social login buttons
- **Market & News Cards** — live-style coin price list (BTC, ETH, BNB, SPCXB, NVDAB) with tabs, plus a news headline list
- **SAFU Section** — press recognition row, "Funds Are SAFU" info block with wallet address and stats, video cards
- **Download Section** — QR code + app platform links
- **FAQ Section** — expandable question list
- **Footer** — multi-column sitemap (Community, About Us, Products, Business, Service, Learn, Support), social icons, language/currency/theme settings, legal disclaimer, and a final CTA banner

## 🎨 Design

- Dark theme matching Binance's color palette (`#0b0e11`, `#1e2329`, `#f0b90b` yellow accent)
- Layout built with Flexbox and CSS Grid
- Responsive breakpoints for tablet and mobile widths
- Icons are currently emoji/text placeholders — swappable for SVGs for a closer visual match

## 🚀 Usage

```
git clone <https://github.com/karanfutela/Binance-Clone>
cd binance-clone
open index.html
```

## ✅ Status / Known Limitations

- Static only — buttons, dropdowns, and the theme toggle are visual, not functional (no JS)
- Images referenced (`google.svg`, `apple.png`, `pic1.png`, `vid1.png`, etc.) are placeholders and need to be added to the project folder
- Built for learning/practice: replicates layout and styling, not live data

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, media queries)
